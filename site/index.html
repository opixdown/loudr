Voice typing

Hold. Speak. Release.

Hold Right Option (Right Alt on Windows) and talk. When you let go, the text is typed wherever your cursor is: an editor, a chat, a browser, a terminal.

Text to speech

Select. Tap. Listen.

Select text in any app and tap one key to hear it. Or paste a script, pick one of nine voices, and save it as an MP3.

Good to know

The first time you open it

Loudr isn't signed with a paid developer certificate yet, so your system will warn you once.

Mac: right-click Loudr in Applications and choose Open. If macOS says the app is damaged, run xattr -cr /Applications/Loudr.app in Terminal and open it again.

Windows: in the SmartScreen box choose More info, then Run anyway.

What it downloads

The installer is about 22 MB on a Mac and 32 MB on Windows. On first run Loudr downloads a speech-recognition model (142 MB by default). Text to speech is optional and needs a 205 MB voice. After that it never goes online.

What it needs

A Mac with Apple Silicon, or a 64-bit PC with Windows 10 or 11. On a Mac it asks for Microphone and Accessibility access, to hear you and to type for you. The Windows version is new and less tested; please report anything odd on GitHub.
